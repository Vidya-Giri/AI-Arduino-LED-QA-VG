# AI-Assisted Arduino LED QA Project

## Project Title
Arduino LED Blinking System

## Objective
The objective of this project is to implement a simple
LED blinking system and analyze its code quality using AI.

## Tools Used
- Arduino
- Arduino IDE
- GitHub
- ChatGPT

## Working
The LED turns ON for one second and OFF for one second
continuously.

## QA Approach
The code was analyzed using AI to identify possible
timing, blocking, and code quality issues.
